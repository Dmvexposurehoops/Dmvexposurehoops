Class rankings

Edit the list and order for a class, then publish the corresponding rankings page.

Rank numbers are automatically assigned from the row order. For 2027–2029, the dashboard updates each class's rankings data. For 2030, it updates the visible rankings section.

Monthly watchlists

Manage player names, heights, and order for a class and month.

This updates the chosen month inside that class's existing watchlist page. Rank numbers are automatically assigned based on row order.
Admin tools are not linked from the public navigation. GitHub Pages is a static host, so GitHub stores each change as a commit and then publishes the site after its normal build delay. The dashboard itself is not an authentication system; access to edits is controlled by the GitHub token you enter.
